## Selected work

### [Reprise](https://github.com/marvinbaudach/reprise) — native music player for GNOME *(active alpha)*

A portable Rust core owns the domain: library, queue semantics, scanning,
playlists, and settings. Everything Linux-specific — GStreamer playback, MPRIS,
MTP, keyring — sits behind explicit contracts in a separate crate, so the core
never learns about the platform it happens to run on.

Four frontends run on that one core: the GTK4/libadwaita GNOME app, an Android
client, a headless CLI, and an MCP server that exposes the library to coding
agents. Architecture boundaries, accessibility, and performance budgets are
enforced by scripts and tests, not described in a document and hoped for.
